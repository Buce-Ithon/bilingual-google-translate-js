# Introduction

This project is an light and reliable auxiliary extension for the "Google Translate" Chrome extension, designed to display both the original text and its Google-translated version side-by-side for bilingual comparison.
The extension is intended solely for personal study purposes. In its current state, it can reliably identify and display a significant portion of text in a bilingual format—which is sufficient for my own reading and browsing needs—so no major updates are planned for the near future. As it cannot guarantee 100% perfect recognition or meet every specific requirement, please feel free to submit an issue if you encounter any problems while using it.

# 项目介绍

该项目旨在构建一个 Chrome 中的 "Google Translate" 插件的轻量化可靠的辅助插件，用于同时显示"原文+GT翻译后的译文"，进行双语对照显示。
插件仅供个人学习使用，当前只能简单识别相当一部分的文本并对其进行双语对照显示，已经满足本人浏览阅读的使用需求，所以短期内不会进行大幅度更改。由于不能保证100%完美识别或完美满足您的需求，所以如您在使用中有如何问题，欢迎提交issue交流。
